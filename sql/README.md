💻 SQL SCRIPTS & DATA ANALYSIS

1. Overview

This folder contains the SQL scripts developed for the AnalystLab Africa Airbnb Market Performance and Listing Insights Dashboard project.

SQL is used to inspect, validate, prepare and analyse the supplied Airbnb datasets.

2. SQL Scripts

The folder is organised into the following scripts:

Script

Purpose

01_data_inspection.sql

Inspect datasets, table structures, columns and data types.

02_data_quality_checks.sql

Investigate missing values, duplicate records, identifier consistency and unusual prices.

03_data_preparation.sql

Perform documented data preparation and transformations.

04_analysis_queries.sql

Answer the assignment's business questions using SQL.

3. Analysis Areas

The SQL analysis supports:

Listing distribution across the selected cities.

Room type and property type comparisons.

Advertised price analysis within local currencies.

Host response and acceptance indicators.

Review activity and review counts.

Listing-level review score comparisons.
