📊 POWER BI DASHBOARD

1. Overview

This folder contains the Power BI dashboard developed for the AnalystLab Africa Airbnb Market Performance and Listing Insights Dashboard project.

The dashboard will provide interactive insights into Airbnb listing distribution, advertised pricing, property characteristics, host performance indicators and historical review activity across 10 selected cities.

2. Dashboard Pages

The dashboard will contain four main pages:

Page

Description

1. Airbnb Market Overview

Presents total listings, selected cities, listing distribution, room types and property types.

2. Pricing and Property Analysis

Explores advertised prices by city and room type, accommodation capacity and property characteristics.

3. Host Performance Analysis

Examines listings per host and available host response and acceptance indicators.

4. Review Activity and Listing Scores

Analyses review records, historical review activity and available listing-level scores.
